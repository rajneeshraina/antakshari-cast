1. Song & Word List (CSV)

A single CSV file with columns: Category, Subcategory (optional), QuestionNumber, MP3Link, Title (optional), Seconds (optional), LyricsLink (optional), Answer (optional), Words (optional). MP3Link should just be the filename of a media file (e.g. song12.mp3) that lives in the folder you'll select in step 2 — audio, video, or image files all work. LyricsLink can be a filename of a text file in that same folder (e.g. song12.txt) or a direct URL — when present, a "📄 Lyrics" button appears during that song to show the lyrics in a popup. Answer is plain text — when present, an "✅ Answer" button appears to reveal it in a popup. Words is used for the Word Round — put one word per row in this column (any rows without a value in Category/QuestionNumber are ignored for songs but their Words value is still collected), so you can list as many words as you like even if you have fewer songs.
